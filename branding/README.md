# AudioViz logo concepts

Concept **A — Signal** was selected for the Windows app icon. `AudioViz.ico`
contains 16, 32, 48, 64, 128 and 256 px sizes generated from its SVG master.
The other concepts remain here as design history.

- **A — Signal:** instantly reads as a music visualizer and stays legible small.
- **B — Wave ring:** premium audio motif with a soft circular silhouette.
- **C — AV:** compact wordmark-style monogram, more distinctive as a brand.

Shared palette: midnight `#081A2A`, cyan `#6AE1E6`, violet `#7768ED`.
The icons are square SVG masters suitable for a later Windows `.ico` export.
